# Память проекта AOI Elks

---

## Назначение

Android-приложение для **оффлайн** оптической инспекции СМД-монтажа **произвольных** печатных плат.
Каталог типов плат на устройстве: эталон + название, проверка по камере.

---

## Ключевые требования

1. Оффлайн — фото не уходят в сеть
2. Компоненты от 0603, односторонний СМД
3. Брак → звук + красный квадрат
4. Оператор держит телефон, следует графическим подсказкам
5. Фонарик автоматически; без ручного управления камерой
6. Несколько типов плат в каталоге
7. OpenCV-выравнивание эталон ↔ снимок

**Название:** AOI Elks

---

## Технические решения

- Kotlin + Compose + CameraX
- OpenCV 4.9: ORB + homography + absdiff + сетка зон
- Fallback без выравнивания при малом числе совпадений
- Room + локальные JPEG
- GitHub Actions → debug APK
- UpdateChecker → GitHub Releases API
- Репозиторий: https://github.com/DexterHtcone/AOI-Elks (public)
