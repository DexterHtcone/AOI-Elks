## Исходные требования от заказчика (хронология)

### 02.08.2026 — Начало

**Контекст:**
- Предприятие производит изделие, в которое входит плата **Эл242** (Элекс242 ОД2503).
- На плате есть группа элементов с СМД-монтажем.
- Нужно приложение, которое обнаруживает брак СМД-монтажа с помощью камеры телефона.

**Ответы на уточняющие вопросы:**

1. **Оффлайн** — очень желательно работать без интернета, или хотя бы не отправлять фото платы через интернет.
2. **Размер элементов** — 0603. Меньше нет. Монтаж СМД **односторонний**. Процессор в корпусе на **48 выводов**.
3. **При обнаружении брака** — программа издаёт звук и индицирует **красным квадратом** область с браком для последующей коррекции.

### Дополнительные требования

1. Оператор **держит телефон в руках** и следует **графическим подсказкам** программы (поворачивал, наклонял, приближал, удалял).
2. **Освещение**:
   - Программа может использовать вспышку телефона в режиме фонарика.
   - Возможно регулировать яркость.
   - Рекомендовать улучшить освещение.

**Название проекта:** AOI Elks

### 02.08.2026 — Расширение (v1.1)

- Приложение должно поддерживать **несколько типов плат**, а не только одну.
- На телефоне формируется **каталог плат**.
- Каждая плата в каталоге имеет своё эталонное фото и может быть выбрана для проверки.

## Наблюдения по реальной плате Элекс242 ОД2503 (фото + видео)

- Маркировка: «Элекс242 ОД2503 μkHz»
- Крупный 48-выводный процессор (DD4) — отличный ориентир
- Электролит C5 (22 мкФ 25В), жёлтый конденсатор C38
- Разъём X13 (IDC-10)
- Много 0603+ компонентов, односторонний монтаж
- Сильные блики и разное освещение на реальных фото
- Операторы ставят чёрные стрелки на проблемные зоны

## Принятые технические решения

- **Платформа:** Android (Kotlin + Jetpack Compose + CameraX)
- **Подход MVP:** Эталонное сравнение + выравнивание + простые эвристики
- **Каталог плат:** Room + локальные файлы эталонов
- **ML:** TensorFlow Lite — на более поздних этапах
- **Сборка:** GitHub Actions → Debug APK
- **Репозиторий:** https://github.com/DexterHtcone/AOI-Elks (private)
