# Техническое задание и план работ
## Проект: **AOI Elks**
### Автоматизированная оптическая инспекция СМД-монтажа печатных плат

**Версия:** 1.2
**Дата:** 02.08.2026
**Статус:** MVP + OpenCV
**Изменения v1.2:** Обобщение — приложение не привязано к конкретному типу платы

---

## 1. Цель проекта

Разработать мобильное Android-приложение для оперативного обнаружения брака СМД-монтажа **произвольных** печатных плат с помощью камеры смартфона.

Приложение должно:
- Работать **полностью оффлайн** (фото не покидают устройство)
- Поддерживать **несколько типов плат** через локальный каталог
- Помогать оператору правильно позиционировать телефон с помощью графических подсказок

Тип платы задаётся пользователем при добавлении в каталог (название + эталонное фото).

---

## 2. Основные требования

### 2.1. Функциональные требования

| № | Требование | Приоритет |
|---|-----------|---------|
| 1 | Захват изображения платы через камеру телефона | Must |
| 2 | Полностью оффлайн-работа | Must |
| 3 | Каталог плат — добавлять, выбирать, удалять разные типы | Must |
| 4 | Для каждой платы: название, описание, эталонное фото | Must |
| 5 | Графические подсказки позиционирования | Must |
| 6 | Автоматический фонарик + рекомендации по освещению | Must |
| 7 | Обнаружение брака СМД (отсутствие, смещение, tombstone и др.) | Must |
| 8 | При браке: звук + красный прямоугольник | Must |
| 9 | Поддержка компонентов от 0603 и крупнее | Must |
| 10 | Калибровка / добавление эталона | Must |
| 11 | OpenCV-выравнивание (ORB + homography) | Must |
| 12 | Проверка обновлений с GitHub Releases | Should |
| 13 | История проверок | Should |

### 2.2. Нефункциональные

- Android 8.0+ (API 26+)
- Интерфейс на русском
- Данные только локально на устройстве

---

## 3. Каталог плат

```
BoardProfile {
  id, name, description, createdAt, updatedAt,
  referenceImagePath, thumbnailPath
}
```

Сценарий: каталог → выбор платы → проверка / перекалибровка / удаление.

---

## 4. Архитектура

- Kotlin, Jetpack Compose, CameraX
- OpenCV Android (ORB, homography, absdiff)
- Room + файлы эталонов
- GitHub Actions → APK

---

## 5. Критерии MVP

- Несколько плат в каталоге
- Проверка с подсказками и детекцией
- Оффлайн
- Сборка через GitHub Actions
