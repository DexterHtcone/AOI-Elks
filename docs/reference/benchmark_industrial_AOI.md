# Референсные характеристики промышленной АОК-системы

Справка для сопоставления с AOI Elks. Данные — по паспортным характеристикам настольной системы автоматической оптической инспекции среднего класса (5 Мпикс, четырёхканальная кольцевая подсветка R/G/B/W), 2026 г.

Источник — коммерческие материалы поставщика. **Реквизиты продавца, цены и банковские данные в настоящую справку намеренно не включены** (публичный репозиторий).

## 3. Вывод

Разрыв между мобильным приложением и промышленной системой определяется не алгоритмами, а **физикой съёмки**: разрешением, геометрией освещения и повторяемостью позиционирования. Алгоритмическая часть (выравнивание, сравнение с эталоном) во всех трёх случаях сопоставима по сложности.

Отсюда роли:
- промышленная система — контроль пайки и мелких компонентов;
- АОК-1 — то же в уменьшенном объёме, при стоимости оборудования на порядок ниже;
- AOI Elks — вспомогательный инструмент оператора для быстрой проверки установки крупных компонентов и фотофиксации, без претензии на контроль пайки.
