# AOI Elks

**Автоматизированная оптическая инспекция СМД-монтажа печатных плат**

Android-приложение для обнаружения брака поверхностного монтажа с помощью камеры смартфона.

## Основные возможности

- Полностью оффлайн-работа
- Каталог нескольких типов плат
- Графические подсказки оператору (позиционирование)
- Автоматический фонарик
- OpenCV: выравнивание (ORB + homography) и сравнение с эталоном
- Звуковой сигнал + красная подсветка проблемных зон
- Проверка обновлений с GitHub Releases
