# AOI Elks

**Автоматизированная оптическая инспекция СМД-монтажа платы Эл242**

Android-приложение для обнаружения брака поверхностного монтажа с помощью камеры смартфона.

## Основные возможности

- Полностью оффлайн-работа
- Графические подсказки оператору (поворот, наклон, зум)
- Использование вспышки телефона
- Обнаружение дефектов СМД (отсутствие компонента, смещение, tombstoning и др.)
- Звуковой сигнал + красная подсветка проблемных зон
- Поддержка компонентов от 0603 и процессора 48 pin
